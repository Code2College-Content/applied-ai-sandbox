# M5 -- Task Decomposition

## Task 1: Add `parse_tags` helper to `app.py`

**What:** Add a pure function `parse_tags(s: str) -> list[str]` to `app.py`. It takes a raw comma-separated string from a form field and returns a clean list of tags -- split on commas, each entry stripped of whitespace, empty strings dropped.

**Why first:** Every other task that touches tags depends on this logic. Isolating it as a named function means the route code stays simple and the behavior is easy to test in one place.

**File to change:** `app.py` -- add the function above `create_app`.

**How to verify:** Write `tests/test_tags.py` with a few direct calls to `parse_tags`:
- `parse_tags("")` returns `[]`
- `parse_tags("work, urgent , ")` returns `["work", "urgent"]`
- `parse_tags("  personal  ")` returns `["personal"]`

Run `pytest tests/test_tags.py -v` -- all pass. Run `pytest -v` -- existing tests still pass.
