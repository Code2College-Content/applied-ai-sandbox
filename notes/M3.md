## Step 4 — good-context plan

 Plan: Login Flow for Applied AI Sandbox
Context
The sandbox currently has no auth — notes are stored in one shared in-memory list. Adding Flask-Login gates the app so each user sees only their own notes. This is a learning exercise, so the implementation stays simple and self-contained.

Key tension: existing tests vs. login_required
test_task_01.py POSTs to /notes/new without logging in. Adding @login_required to that route will cause those requests to redirect to /login (302) instead of running the form validation, breaking all existing tests.

Resolution (pending user approval): Add a before_request hook inside create_app() that auto-logs-in a test user when app.config["TESTING"] is True. No changes to tests/. Conftest already sets TESTING=True so existing tests get a free authenticated session transparently.
