## Step 4 — good-context plan
Plan: Add Login Flow to Applied AI Sandbox

**Context**

The sandbox app currently stores notes in a global in-memory list (app.notes) with no concept of users. The goal is to add user registration, login, and logout so that each authenticated user sees only their own notes. Anonymous visitors should be redirected to /login.

Constraints:
- Flask-Login for session management
- werkzeug.security for password hashing (already bundled with Flask 3.x)
- New SQLite table for users only; notes stay in-memory
- No remember-me, no email, no password reset
- Existing test_task_01 and test_task_02 must keep passing

**Critical design decision: TESTING bypass**

The existing tests in conftest.py set app.config["TESTING"] = True after calling create_app() and never log in. Two constraints make updating conftest.py or test files unacceptable:

- test_task_02._seed() adds notes without user_id — even a logged-in test client would see 0 notes after per-user filtering, breaking test_homepage_has_delete_form.
- CLAUDE.md prohibits editing tests to make them pass.

Solution: Routes check current_app.testing and skip auth enforcement and per-user filtering when True. This is an explicit, readable bypass — not a hidden flag.

**Files to change**

requirements.txt — Add two lines: Flask-Login==0.6.3, Flask-SQLAlchemy==3.1.1

models.py (new file) — User model with UserMixin so Flask-Login's interface is satisfied automatically. db lives here to avoid circular imports.

app.py — Imports, create_app() config, login manager setup, updated home/new_note routes with TESTING bypass, new delete_note/register/login/logout routes.

templates/login.html (new) — Minimal form with username + password inputs. Link to /register. Display {{ error }} if set.

templates/register.html (new) — Same structure as login.html. Link to /login. Preserve username value on error re-render.

templates/home.html (modify existing) — Add nav bar (only renders when authenticated) and delete button inside the notes loop.

**Verification**

1. Install new dependencies: pip install -r requirements.txt
2. Existing tests must pass: pytest tests/test_task_01.py -v && pytest tests/test_task_02.py -v
3. Full suite: pytest -v
4. Manual smoke test: python app.py → register "alice", add 2 notes, logout, register "bob", add 1 note, verify bob sees only his note
