## Step 2 — CLAUDE.md behaviors

1. To ensure that Claude doesn't go off the rails, the sections "What this project is" and "Conventions" explicitly state where Claude should pull information and how it should go about solving the problem.
2. By providing Claude the instruction to only work on one task at a time, it helps us (the students) more easily work through the problems as it recognizes that other errors come from parts that we haven't gotten to just yet and is able to inform us of such.
3. By informing Claude of the stack and what the project is, Claude is able to create a more comprehensive and complete picture of what it need to do to help the user in this case learn how to use Claude AI.

## Step 3 — bad-context run

1. Whilst coding, Claude created a full new registry for users to create an account and log in, which means that it assumed there were no other logins I had stored or a better database to store those in.
2. Although I wasn't able to find anything that it got wrong, I started with a broad question which meant that Claude took a lot of liberty in creating it's own systems alongside what already existed to fit what it thought was best.
