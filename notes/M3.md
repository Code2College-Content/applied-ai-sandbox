## Step 4 — good-context plan

Plan: Add Login Flow to Sandbox App

Context: The sandbox app currently has no authentication. Notes are stored in a shared in-memory list. The goal is to add register, login, and logout so each user sees only their own notes.

Key design tension: Existing tests expect anonymous access, so Claude plans to preserve test behavior while redirecting anonymous users in normal app usage.

Files to change:
- requirements.txt: add Flask-Login.
- models.py: create a new User model/helper functions using SQLite and werkzeug password hashing.
- app.py: wire Flask-Login, add register/login/logout routes, and filter notes by current user.
- templates/login.html and templates/register.html: add forms for authentication.
- templates/home.html: add logout/user navigation.

Note storage design: Keep the existing in-memory notes list, but add a user_id field to new notes so logged-in users only see their own notes.

Verification:
- Install Flask-Login.
- Run pytest.
- Manually test registering user A, creating a note, logging out, registering user B, and confirming user B does not see user A's note.
