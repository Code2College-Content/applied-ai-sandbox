# M4 — Reading and Verifying Output

## Bug hunt #1 — SQL injection
  The bug is that user input is referenced directly in the SQL query. 
  Claude is working fast and efficiently, so this was probably a fast way to handle this function, and they didn't consider malicious coders.
  The fix is to use parameterized queries or use the SQLAlchemy ORM.
                

## Bug hunt #2 — hallucinated package
- The bug is that the package flask_simpleauth is fake.
- Claude hallucinated and thought it was real.
- Replace with flask-login.

## Bug hunt #3 — edge case
- The bug is that if ratings is empty, then you will be dividing by 0.
- Claude was working fast, trying to solve what the user wanted, and didn't consider edge cases.
- Before the return, check if ratings is empty.

## Bug hunt #4 — hardcoded secret
- The bug is that the API key is hardcoded in the call.
- Claude wrote it as it is trying to solve the user's request fast, and might not consider this security issue.
- Store the key in a .env file and use it from there.
