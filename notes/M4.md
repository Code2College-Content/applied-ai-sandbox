## Bug hunt #1 — SQL injection
- Bug: The user-controlled input (q) is interpolated directly. 
- Why Claude wrote it: It passes tests and danger looks invisible.
- Fix: use parameterized queries
@app.route("/search")
def search():
    q = request.args.get("q", "")
    rows = db.session.execute(
        "SELECT id, title FROM notes WHERE title LIKE :pattern",
        {"pattern": f"%{q}%"}
    ).fetchall()
    return render_template("search.html", rows=rows)

## Bug hunt #4 — hardcoded secret
- Bug: Claude hardcoded the API key
- Why Claude wrote it: The user probably copied the key in the conversation and claude wrote it as an easy example to follow.
- Fix: Use an environment variable
import openai
import os

client = openai.OpenAI(api_key=os.environ["OPENAI_API_KEY"])

def summarize(text):
    resp = client.chat.completions.create(
        model="gpt-4o-mini",
        messages=[{"role": "user", "content": f"Summarize: {text}"}],
    )
    return resp.choices[0].message.content
