# M6 — Other Tools Tour

## Copilot — installed
Copilot was fastest for small boilerplate and autocomplete tasks, but it didn’t follow project-specific conventions as reliably as Claude Code.

## Cursor (or Windsurf) — installed
I’d use Cursor for quick multi-file edits and repository exploration because the inline diff workflow feels very fast and interactive.

## Gemini CLI (or Codex CLI) — installed
Gemini CLI felt faster at scanning the codebase, while Claude Code gave more accurate and structured explanations of the project.

## Chat (Claude.ai or ChatGPT) — used for
Chat caught that the PR didn’t handle empty-state validation properly, which is the kind of edge case a junior reviewer should flag.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
|---|---|---|
| Multi-file feature with good CLAUDE.md | Claude Code | Reads project conventions and handles structured repo-wide changes well |
| 5-line helper autocomplete while typing | Copilot | Fast inline suggestions without interrupting flow |
| Brainstorm three design approaches | Chat | Best for planning and tradeoff discussion before coding |
| Quick repo-wide refactor | Cursor | Inline multi-file diffs and fast context navigation |
| Compare model behavior on same coding task | Gemini CLI | Easy terminal-agent comparison and different reasoning style |
| Review a PR for risks and edge cases | Chat | Strong at critique, explanation, and identifying missing considerations |
