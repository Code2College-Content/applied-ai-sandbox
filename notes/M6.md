# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: Good for fast inline autocomplete, but does not understand project rules or broader context.

## Cursor (or Windsurf) — installed/demo'd
- Observation: Able to generate multi-file changes from a single prompt but over-assumes intent often

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Claude was more structured and repo-aware but gemini was faster and less consistent

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Helpful for reviewing code diffs and explaining concepts but deos not edit

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude| Understands repo rules and makes structured changes|
| 5-line helper autocomplete while typing |copilot | fast inline suggestions|
| Brainstorm three design approaches | Chat| better ideation with less execution pressure|
| Review a teammate's PR for security issues | Chat| reasons about risks in isolation|
| Cross-file refactor with consistent renames | Cursor| strong multi-file agent diffs|
| Learning a new library's API | Chat| clearer explanations without code noise|
