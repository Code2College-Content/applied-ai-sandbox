## Chat (Claude.ai or ChatGPT) — used for
- Observation: Asks for files, but is then able to accurately test the code and implement it.

## Tool decision matrix

- **Multi-file feature with good CLAUDE.md** → Claude Code
  - Reads project context automatically, plans and edits across multiple files in one session

- **5-line helper autocomplete while typing** → GitHub Copilot
  - Inline autocomplete as you type is Copilot's core strength — no context switching needed

- **Brainstorm three design approaches** → Claude.ai / ChatGPT
  - Open-ended chat is better for comparing ideas and thinking out loud before writing any code

- **Review a teammate's PR for security issues** → Claude Code (`/security-review`)
  - Can read the full diff and flag security issues with line-level references

- **Cross-file refactor with consistent renames** → Claude Code
  - Understands the whole codebase and applies consistent changes across every affected file

- **Learning a new library's API** → Claude.ai / Gemini CLI
  - Great for Q&A, examples, and explanations without needing to be inside a project
