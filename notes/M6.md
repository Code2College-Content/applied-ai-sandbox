# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: Tightly integrated into VS Code and JetBrains; excels at line-level and block completions while you type, but tends to be conservative — it rarely proposes large structural changes and works best when you already have surrounding context in the file.

## Cursor (or Windsurf) — installed/demo'd
- Observation: Chat-native workflow feels more like pair programming than autocomplete; the "apply diff" loop is fast, but the model can over-engineer solutions if the prompt isn't scoped tightly — very similar to the scope discipline issues we've seen with Claude Code.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Given the same "add input validation to this form" prompt, Gemini CLI produced a working solution but added extra sanitization helpers that weren't asked for; Codex CLI stayed closer to the minimal change but occasionally hallucinated function names from the standard library.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Chat interfaces shine for exploration and explanation — asking "why does this pattern exist?" or "what are the tradeoffs?" — but require manual copy-paste to apply changes, which introduces drift; developers who stay in chat too long tend to accumulate suggestions they never actually verify in the running app.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | Knows the project; applies and tests changes |
| 5-line helper autocomplete while typing | Copilot | Instant inline; no context switch |
| Brainstorm three design approaches | Chat (Claude.ai / ChatGPT) | Best for open-ended exploration |
| Review a teammate's PR for security issues | Claude Code /code-review | Diff-aware; posts inline comments |
| Cross-file refactor with consistent renames | Cursor | Multi-file diff keeps renames consistent |
| Learning a new library's API | Chat (Claude.ai / ChatGPT) | Back-and-forth beats one-shot answers |
