# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: Copilot feels easier to work with because I have an IDE I can see, but Claude's code was often times more right, and Claude understood my prompts better.

## Cursor (or Windsurf) — installed/demo'd
- Observation: With the AI being built into the IDE, Cursor is also a lot easier to work with than Claude, I like it a bit more than Claude because it's easier for me to reference various aparts of my codebase.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Claude was a lot faster and better at navigating the codebase than Gemini. Perhaps, because I have been using Claude Code it is more familiar with this codebase.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: With Claude.ai, it sometimes focuses on the last portion of my message completely skipping everything else. This causes Claude to mess up frequently.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| Multi-file feature with good CLAUDE.md |Claude Code | Claude code looks for CLAUDE.md |
| 5-line helper autocomplete while typing |Cursor |IDE and AI are intertwined, so autocomplete works well here. |
| Brainstorm three design approaches |Chat GPT |Chat GPT is really good at creating images to visual designs. |
| Review a teammate's PR for security issues |Copilot | Copilot can anaylze PRs. |
| Cross-file refactor with consistent renames |Claude Code | Claude code has access to my entire codebase, and starts off each prompt looking through the codebase, so I would trust it with this as I know it knows my codebase. |
| Learning a new library's API |Claude ai |Claude.ai is good in teaching code. |
