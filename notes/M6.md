# M6 — Other Tools Tour

## Copilot — installed/demo'd
- Observation: It is able to predict what my code is going to be about based on patterns. It can't implement if there is not a basic outline.

## Cursor (or Windsurf) — installed/demo'd
- Observation: Can't be installed in vs. It is uncomfortable and have to directly upload files/

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Claude was faster and it was able to provide more information. But, I liked gemini's more compact summary as it was easier to understand.  

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Asks for files, but is then able to accurately test the code and implement it.
