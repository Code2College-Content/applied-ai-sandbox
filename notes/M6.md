# M6 - Other Tools Tour

## Copilot — installed/demo'd
- Observation: Copilot is fast for boilerplate and inline completions but pattern-matches off surrounding code only — it has no awareness of project conventions, CLAUDE.md, or broader architecture, so it's great for a quick helper function but can't be trusted to follow team rules without prompting.

## Cursor (or Windsurf) — installed/demo'd
- Observation: Cursor wins for quick multi-file edits where you want to see an inline diff before committing — it's faster for small contained changes, but Claude Code has the edge on longer agentic tasks where CLAUDE.md conventions and plan-mode review matter.

## Gemini CLI (or Codex CLI) — installed/demo'd
- Same prompt comparison: Claude Code gave a more structured and accurate summary that reflected actual project conventions, while Gemini CLI was faster to respond but skimmed the codebase more superficially — Claude wins on depth, Gemini on speed for throwaway questions.

## Chat (Claude.ai or ChatGPT) — used for
- Observation: Chat is the right tool for code review and planning where you want reasoning without execution — pasting the M5 Task 1 diff surfaced that the tags default should live in a helper rather than inline in the route, the kind of design note a junior reviewer would miss but matters at scale.

## Tool decision matrix
| Situation | Tool I'd reach for | Why |
| --- | --- | --- |
| Multi-file feature with good CLAUDE.md | Claude Code | Reads conventions, plans before acting, respects project rules |
| 5-line helper autocomplete while typing | Copilot | Inline, zero context-switching, fast tab-to-accept |
| Brainstorm three design approaches | Claude.ai chat | No code yet, just reasoning — chat is the right shape |
| Review a teammate's PR for security issues | Claude.ai chat | Paste the diff, get a focused review without needing file access |
| Cross-file refactor with consistent renames | Cursor | Inline multi-file diff lets you see and approve every change before it lands |
| Learning a new library's API | Claude.ai chat | Conversational back-and-forth beats a terminal agent for pure learning |
