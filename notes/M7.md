## Feature I picked
- A "starred" filter (toggle to show only starred notes)


## Plan from chat
1. Data layer — add starred field
Each note needs a boolean starred property. If you're using local state, add it to each note object: { id, title, body, starred: false }. If there's a database (Supabase, etc.), add a starred boolean column with a default of false.
2. Star/unstar action
Write a toggleStar(id) function that flips starred on the matching note. In React this looks like:
jsconst toggleStar = (id) =>
  setNotes(notes.map(n => n.id === id ? { ...n, starred: !n.starred } : n));
3. Filter state
Add a showStarredOnly boolean to state (default false). Derive the displayed list:
jsconst visibleNotes = showStarredOnly ? notes.filter(n => n.starred) : notes;
4. UI — star button on each note
Add a ⭐ button to each note card/row. It should call toggleStar(note.id) on click and visually reflect the current state (filled vs. outline star).
5. UI — filter toggle
Add a toggle button (or checkbox) somewhere in the toolbar/header that flips showStarredOnly. When active, it should have a highlighted/active style so the user knows filtering is on.
6. Edge case — empty state
If showStarredOnly is true but no notes are starred, show a message like "No starred notes yet" instead of a blank list.
