# M7 – Starred Notes Feature

## What was built

A "starred" filter for the notes homepage. Users can star any note and toggle a toolbar button to show only starred notes.

## Changes

**`app.py`**
- Notes now include `"starred": False` by default when created.
- New route `POST /notes/<idx>/star` toggles `note["starred"]` and redirects home. Returns 404 for out-of-range index.

**`templates/home.html`**
- Each note card has a ☆/★ button (top-right) that submits a form POST to `/notes/<idx>/star`.
- A "★ Starred" toolbar button toggles a `starred-only` CSS class on `<body>`, hiding unstarred notes via CSS (`.starred-only .note:not(.starred) { display: none }`).
- Empty state message ("No starred notes…") is shown when the filter is active but no starred notes exist.

**`tests/test_task_m7.py`** — 6 new tests covering defaults, toggle on/off, 404 on bad index, icon presence, and CSS class.

## Key decisions

- **Form POST for star toggle** (not PATCH/JSON) — consistent with existing app patterns.
- **Client-side filter via CSS class toggle** — purely ephemeral, resets on reload, no server round-trip needed.
- **Star icon always visible** — simpler than hover-only; no extra JS required.

## Acceptance criteria

- [x] Clicking ★ persists starred state (survives page reload).
- [x] "Starred only" toggle hides unstarred notes; friendly empty state shown when none are starred.
- [x] Unstarring the last note in "starred only" view reveals the empty state immediately.
