# M7 — Multi-Tool Workflows

## Feature I picked
- add a calendar feature which can show when a note is due.

## Plan from chat
Data model
due_date
Date | null
— one new field on Note
No new tables. No new models. Just a nullable date column on the existing notes table.
Routes
PATCH /notes/:id — add due_date to the existing update payload. No new endpoint needed.
GET /notes?due_date=2025-06 — optional filter so the calendar view can fetch notes for a given month.
UI changes
Note editor gets a small date picker field — "Due date" — below the title. Optional, easy to clear.
Note cards show a subtle date badge when a due date is set. Nothing when it isn't.
New calendar view (month grid). Days with due notes get a dot indicator. Click a day → see the note titles for that day.
Edge cases
Past due dates — show the badge in red, no blocking or warnings.
Multiple notes on the same day — stack them in the day cell, truncate after 3 with a "+N more" link.
Deleting a note removes its due date from the calendar automatically (no orphaned entries).
Timezone — store as UTC, display in user's local timezone.
