## Plan from chat
Create a 1 page design no code. For a note taking fullstack app with a python backend, create a search bar to search through notes by title.

The design shows a full-page app layout with two zones: a sidebar and a main content area.
Sidebar — search experience:

The search bar filters notes by title in real time as you type, with match highlighting on the results
A clear (×) button appears when there's text in the field
A results count label updates dynamically ("3 results for 'notes'")
Clicking any note sets it as active (green border indicator)

Main content:

Shows the selected note's title, tags, and a body preview
Includes a callout showing the Python backend endpoint pattern: GET /api/notes?q={title} using a LIKE '%title%' query on SQLite, returning JSON ordered by updated_at

Design direction: editorial/utilitarian — Lora serif for a notepaper feel, JetBrains Mono for metadata and code, teal accents throughout, clean 0.5px borders everywhere.
